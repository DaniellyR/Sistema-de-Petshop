## 📌 Sobre o Projeto
O **PetShop Carinho** é um sistema web desenvolvido como projeto acadêmico para gerenciar o agendamento de serviços para pets (como banho e tosa). O objetivo principal do projeto foi construir uma aplicação Full-Stack do zero, integrando um front-end interativo com um back-end funcional e persistência de dados em um banco de dados relacional (CRUD).

## 🚀 Funcionalidades
* Interface amigável para o cliente realizar agendamentos.
* Seleção interativa de serviços (Banho, Tosa, Combo) e dados do pet (Macho/Fêmea).
* Validação de formulários no front-end.
* Envio de dados assíncrono utilizando a API `Fetch`.
* Roteamento no back-end gerenciando requisições e respostas (`req` e `res`).
* Inserção de dados estruturados diretamente no banco de dados MySQL.

## 🛠️ Tecnologias Utilizadas
**Front-end:**
* HTML5 (Estruturação semântica)
* CSS3 (Estilização, Flexbox, Grid e UI interativa)
* JavaScript Vanilla (Manipulação do DOM e requisições assíncronas)

**Back-end:**
* Node.js (Criação do servidor e rotas utilizando `req.url`)
* Módulo `mysql2` (Integração e execução de Querys SQL)

**Banco de Dados:**
* MySQL (Banco de Dados Relacional)
